# Flora-Guard Project Knowledge

## Project Title

Native Flora Detection and Management System through Computer Vision and Geoanalytics in Talaingod, Davao del Norte

## Project Description

Flora-Guard is a mobile and web-based system designed to detect,
classify, record, and map selected native flora species using
computer vision and geoanalytics.

## Main Users

### Students
- Scan native flora using the mobile application
- View detection results
- Capture photos
- Record GPS coordinates
- View previous scan records

### Environmental/Forestry Experts
- Review submitted scans
- Validate detection results
- Accept or reject records
- Reclassify incorrect detections
- Monitor flora records through the dashboard
